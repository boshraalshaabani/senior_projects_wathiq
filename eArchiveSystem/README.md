Description:
Wathiq is an advanced Enterprise Document Management System designed to transition traditional document handling into a multi-institutional, AI-powered environment. The system features a core Document Understanding Engine that utilizes local LLM Vision models (instead of traditional OCR) to extract structured layouts, tables, and metadata. It also implements an AI Classification Engine to automatically categorize documents and suggest appropriate department routing."
"Key features include hierarchical governance (System, Institution, Department levels), comprehensive document lifecycle management (Versioning, Audit Logs, and Workflows), and intelligent full-text search capabilities. Wathiq is built to support high-security requirements, including sensitivity labeling and automated watermarking, making it suitable for enterprise and governmental use."
